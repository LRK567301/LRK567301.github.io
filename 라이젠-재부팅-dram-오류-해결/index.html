라이젠 재부팅 DRAM 오류 해결

2026-10-29

MSI MAG B650M MORTAR WIFI, 7D76vAO2(2026-07-06).

https://forum-en.msi.com/index.php?threads/b650-tomahawk-wifi-cant-restart-pc-with-expo-on.411124/

Manually set CPU NB/SOC to 1.2v - 1.25v max.

메인보드 설정에서 CPU NB/SOC Voltage를 Override Mode 1.2V. 기본값 Auto 1.016V에서 조금 올리자마자 바이오스 재부팅, 윈도우 재부팅 모두 하루종일 켜져 있었던 DRAM 주황색 LED가 잠깐만 켜져있다 꺼지고 재부팅도 더 빨라진 것 같다.

씨발 이게 이렇게 쉽게 해결될 일이었구나….기록을 찾아보니 라이젠 8000번대 지원(AGESA ComboPI 1.0.9.0)되기 전 3년전 버전(AGESA ComboPI 1.0.0.7c)까지 가야할 것 같아서 MSI 바이오스 플래시백인가 CPU 없이 USB만 가지고 바이오스 덮어쓰기 되는거 믿고 3년을 롤백하는 대모험을 진지하게 고민중이었는데 씨발 이게 이렇게 쉽게……

오랜만에 EXPO PBO 다 켰더니 이환도 더 잘되는 것 같다. 레이트레이싱 빗속 야간 질주라는 빡센 환경인데도 훨씬 나아. 783D 고민하다 보드가 이지랄이면 7600도 제성능 못뽑고 있는것도 제대로 못쓰는게 빡쳐서 지푸라기 잡는 심정으로 똑같은 소리만 하는 제미나이 코파일럿 제끼고 그록이랑 퍼플릭시티에 삽질기록 던져본건데 진짜 답을 찾아줄줄 몰랐어. 이사 이후 1년 가까이 끙끙대다 포기하고 EXPO 끄기에 이르렀던 문제 드디어 해결. 눈물난다.

빗길주행 수십분 버티길래 씨퓨 살렸다고 레이트레이싱도?? 했는데 역시 꿈이었다. 다음날 데이트하러 극장 들어갔더니 그 잠시 워프를 못 버티고 터졌어. 5070의 한계인걸로.
